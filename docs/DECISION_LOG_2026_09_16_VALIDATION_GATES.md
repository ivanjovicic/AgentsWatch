# Decision Log — External Validation Before Expansion

Date: 2026-09-16
Status: accepted strategy update

## Decision

AgentsWatch will not expand from 30-run dogfood directly into learning, routing, dashboards, broad integrations, or team/SaaS packaging.

Two explicit gates are inserted first:

1. **External Value Gate** — prove decision-changing value with real external agent-heavy developers/teams.
2. **Commercial Design-Partner Gate** — prove willingness to pay before team/SaaS investment.

## Why

The September 2026 market has moved materially:
- Cursor provides AI code tracking;
- GitHub provides agent session/audit traceability;
- Qodo provides agent-workflow review/governance;
- adjacent vendors are adding broader agent governance/security.

Therefore generic tracking/observability/governance is not enough differentiation.

The product must prove the narrower independent-verifier thesis:

`Run Contract + attributable delta + evidence + claims/scope verification + vendor-neutral Run Receipt`

## Consequences

Blocked until external/commercial proof:
- SaaS/auth/billing/team administration;
- broad vendor integration marketplace;
- dashboard expansion;
- sophisticated learning/router work beyond trustworthy receipt analysis;
- generic AI-code tracking as a product wedge.

## Kill condition

If external users consistently conclude that Git + CI + PR review + native vendor logs solve the need well enough, do not add unrelated features to rescue the thesis. Narrow or stop.
