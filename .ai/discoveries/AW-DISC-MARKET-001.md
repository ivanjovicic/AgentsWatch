## Evidence summary

Public studies and issue trackers repeatedly report:

- context loss and compaction/session discontinuity;
- unpredictable quota/token consumption;
- repeated no-progress actions;
- false completion and fabricated verification;
- out-of-scope actions and unsafe permission inference;
- fragmented repository rules across coding-agent tools;
- multi-agent worktree contamination and weak coordination;
- review debt from large, misaligned, or unverifiable agent-authored changes.

The strongest AgentsWatch-aligned opportunities are:

1. Agent Flight Recorder and Trust Ledger;
2. Context and Memory Portability;
3. Cost and Loop Guard;
4. Agent Rules Compiler and Drift Detector;
5. Policy Firewall;
6. Multi-Agent Worktree Coordinator;
7. AI PR Review Debt Reducer;
8. Agent Regression Canary.

## Important uncertainty

Desk research proves repeated and intense problem reports. It does not prove:

- market size;
- willingness to install or pay;
- stable provider event inputs;
- acceptable false-positive rates;
- feasibility of local-first live controls;
- security effectiveness;
- popularity of the proposed product shape.
